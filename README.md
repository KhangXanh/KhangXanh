# 👋 Hi, I'm Khang! :D

I'm an indie developer interested in `C++`, **game engine architecture, graphics programming, and low-level systems**.

I enjoy understanding how things work under the hood — from memory allocation and data structures to rendering pipelines and engine architecture. Most of what I learn ends up becoming a small experiment, a sandbox project, or sometimes, an unnecessarily ambitious game engine. :P

---

## 🔨 What I'm Building

### Kryos Engine (Private)

A game engine written in **C++**.

I'm building Kryos from the ground up to explore:

* Engine architecture
* Rendering and Vulkan
* Memory management
* ECS and reflection system
* UI systems
* Asset and resource management
* Editor tooling

*Kryos is currently on a long-term pause while I focus on other things, but I'll be coming back to it. ;)*
